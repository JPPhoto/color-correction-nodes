# color-correction-nodes

> **Superseded:** This node pack is superseded by [`cinematic-effects-pack`](https://github.com/JPPhoto/cinematic-effects-pack). Use the replacement instead; loading both can register duplicate invocation IDs.

The color cast correction node attepts to automatically remove a color cast of the image, replacing it with
the target color selected. The strength parameter indicates the intensity of the color cast removal. Perceptual
lightness is preserved when using this node.
